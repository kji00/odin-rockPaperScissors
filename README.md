# odin-rockPaperScissors

* This is the rock, paper scissors game. This plays in the browser console 5 times and keeps track of the players wins, losses and ties.
* It is assumed that the user enters a valid entry of 'rock', 'paper' or 'scissors' everytime.


# Rock, Paper, Scissors v1.1

* Added UI functionality, where users can choose a button for their choice. The game still keeps track of the score and will show it on screen. 
* You no longer have to use the console.
